SUPER ADMIN Android Project

এই প্রজেক্টটি Android WebView অ্যাপ। এটি আপনার ওয়েবসাইটের বিদ্যমান Login Page খুলবে:
https://okz99.site.je/okz99_staging/login.php

গুরুত্বপূর্ণ:
- অ্যাপ নিজে কোনো Admin Password সংরক্ষণ করে না। ওয়েবসাইটের বিদ্যমান Login/Session ব্যবহৃত হয়।
- ওয়েবসাইটে HTTPS এবং Hosting access ঠিক থাকতে হবে।
- এই ZIP একটি Android Studio source project; APK নয়।

APK বানানোর নিয়ম:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. এই ZIP Extract করে Android Studio-তে ফোল্ডারটি Open করুন।
3. Gradle Sync শেষ হতে দিন এবং Android SDK 35 ইনস্টল করুন।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) চাপুন।
5. APK পাওয়া যাবে app/build/outputs/apk/debug/app-debug.apk পথে।
